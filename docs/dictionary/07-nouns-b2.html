00 Як користуватись блоком повторення

Кожна група має таблицю з трьома перемикачами — вони працюють незалежно для кожної групи.

Сховати переклад (за замовчуванням) — розмита колонка «Українська»: дивіться на іспанське слово, згадуйте переклад, тоді перевіряйте.

Сховати іспанську — навпаки: від українського слова згадайте іспанське разом з артиклем.

Показати все — просто таблиця для читання.

⚠️
Пастка: слова грецького походження на -ma — чоловічого роду, хоча закінчуються на -a: el tema, el trauma, el problema, el sistema, el clima. А -sis — жіночого: la crisis, la hipótesis (але el análisis — виняток!).

11 Що далі

Пройдено рівень B2: 450 із 600 іменників за рівнями (плюс 450 базових). Наступний рівень — C1.

  • Вчіть по одній групі за раз — 15 слів, два проходи (іспанська → українська, потім навпаки).
  • Запам'ятовуйте слово з артиклем — так рід «прилипає» автоматично.
  • Складайте з кожним словом власне речення — пасивно впізнане слово ще не вивчене.
